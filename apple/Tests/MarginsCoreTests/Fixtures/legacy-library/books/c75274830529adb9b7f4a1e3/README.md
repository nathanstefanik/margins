# The Brothers Karamazov

Author: Fyodor Dostoyevsky
Book ID: `c75274830529adb9b7f4a1e3`

## Notes layout

Chapter summaries and annotations live in `notes/chapters/` as Markdown files with YAML frontmatter. Each file is self-contained and agent-friendly.

- `meta.json` — book metadata and chapter spine
- `notes/_index.json` — machine-readable note index
- `notes/chapters/*.md` — one file per chapter note
- `source.epub` — imported EPUB copy
